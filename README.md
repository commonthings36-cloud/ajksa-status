# AJKSA Delivery Status

Live status page for the AJKSA Community Platform.

- `index.html` renders the page. It has no build step.
- `status.json` is the data. To update progress, edit `status` (`Implemented`, `Partial`, `Not implemented`), `start` and `target` for a feature, set `updated`, then commit and push.
- `AJKSA-Feature-Implementation-Status.pdf` is the printable snapshot of 24 Oct 2026.

Host with GitHub Pages (Settings, Pages, deploy from `main`) or Vercel/Netlify.
